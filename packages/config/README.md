# @tangleai/config

Tangle AI configuration — the schema-owned capability-profile registry and effective-run-identity contract every host resolves through

Install with `npm install @tangleai/config`. The npm distribution provides ESM JavaScript, TypeScript declarations, and the documented package subpaths for Node 24 and Bun 1.4 or newer.

See the [Tangle documentation](https://github.com/jklarenbeek/tangleai#readme) for architecture, examples, and runtime requirements. All public Tangle packages use one coordinated version.
