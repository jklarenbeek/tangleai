A manifest can start its icons hidden (`dock: { hidden: true }`), and saving an empty layout gives a person the default dock again. Themes name an ink for the failure colour (`--fail-fg`), so a badge and a hovered close read in dark themes too. The dock sizes itself to its content, keeps a large brand image within its bounds, counts the brand in its tile size, and keeps its tray at the visible end while it scrolls on a phone. The README says what a desktop without `state` keeps: nothing past the page.
