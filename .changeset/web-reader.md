The desktop has Web (`@tangleai/os/web`), a reader of web pages that never frames a third-party site. `webModule({ reader })` takes the host's `WebReader`. The address bar reads an address (a bare host such as `example.org/page` is read over https) and searches for anything else. Back, forward and reload sit in its header bar. A page is drawn from its extracted blocks in the desktop's look, in the page's own language: headings, paragraphs with their links, lists, quotes, code and tables. Nothing a page carries runs or becomes markup. A link on a page opens in the reader (http and https only), and "Open original" opens the address the redirects ended at in a new tab, with no opener and no referrer. A refusal is said plainly with its address, and its code is on the status (`data-code`). Without web access (`OS0180`), Web offers Settings or the host's own `configure`. Its sentences are in all eleven packs. The Pages desktop places Web beside Files, with no web access configured yet.
