## Equal-budget methods

Hash embedding dimensions 512; candidate pool 1000; final k 10; minimum score 0. All comparable rows share one projection per conversation and a source-occurrence-id ordering for score ties. The full finite source pool precedes eligibility. Hash embeddings measure lexical retrieval mechanics, not live embedding quality.

The oracle reads privileged audited annotations and native geometry/time kernels; it never reads the question expectations. The seeded control draws one uniformly selected entry for every question, including kinds that cannot be answered by one entry. Ordinary retrieval chooses the first grounded mention among its top-k turns. The temporal baseline receives the event session instant from the instrument because it cannot join two series. Both baselines record no-geometry on distance/proximity questions. Temporal unknown-validity and no-match losses are retained.

The place method reads complete subject-qualified position series, joins reporting events backward with the native as-of kernel, and then checks the matched claim’s validity. A later exact reporting point can establish a position after an earlier unknown-ended state; an unknown-time assertion, an expired match or an uncertain event still refuses. All event and position citations must fit the same semantic pool and final k. Mention questions call the source-span matcher with the independently audited locative qualification; they do not turn mention status or expected answers into runtime refusals.

The three registered place backends retain independent rows from memory and actual Node/Bun SQLite execution. Nearby probes validate nine contiguous native cells before distance refinement, exclude the centre entry, and refuse radii they cannot cover. An absent runtime or corpus is never a passing zero. Exactness uses the complete registered per-kind denominator; correct refusals are scored by the same exact equality as answers.
