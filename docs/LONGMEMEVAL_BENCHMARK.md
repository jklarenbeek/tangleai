## Time and knowledge

Source stamps are naive calendar minutes, normalized using explicitly synthetic UTC. Weekday and calendar validity are checked. Session time describes source observation and availability, never every event mentioned in that session.

| Profile | QA denominator | Sessions | Future gold sessions excluded | Affected questions retained |
|---|---:|---:|---:|---:|
| provided-history | 500 | 23867 | 0 | 0 |
| strict-as-of | 500 | 22392 | 75 | 44 |

Official retrieval excludes abstentions: 470 questions. QA retains all 500; abstentions overlap question types. Provided-history is retrospective. Strict-as-of removes future sources before runtime input.

Runtime receives opaque IDs, role/content, original ordinals and permitted dates. Gold, source IDs, type, abstention suffix, answer-session membership and all has_answer fields remain evaluator-only. Duplicate session IDs and text keep distinct occurrences. Unsorted inputs retain source ordinals.

The official temporal judge tolerates off-by-one arithmetic; strict kernel results use independent expectations. Question `370a8ff4` has a reported label discrepancy: 81 civil days equals 11 whole weeks plus 4 days; the upstream reference is 15 weeks and remains unchanged.
